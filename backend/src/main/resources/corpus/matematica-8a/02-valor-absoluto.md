
# Valor absoluto

- Curso: Matemática 8° básico A
- Colegio: Colegio Los Andes (demo)
- Unidad: Números
- Tema: Valor absoluto de números enteros
- OA: Matemática 7° básico OA 1 (enteros en la recta numérica) — base para 8° OA 1
- Fuente: Programa de Estudio MINEDUC (curriculumnacional.cl), redactado por el equipo para la demo

## Objetivo
Comprender el valor absoluto como la distancia de un número al cero en la recta numérica.

## Contenido

El valor absoluto representa la distancia entre un número y el cero.

Se escribe utilizando dos barras verticales.

Ejemplos:
- |5| = 5.
- |-5| = 5.
- |0| = 0.

El valor absoluto nunca es negativo porque una distancia no puede ser negativa.

## Comparación de distancias

Los números -4 y 4 tienen el mismo valor absoluto porque ambos están a cuatro unidades del cero.

Sin embargo, son números diferentes.

## Ejemplo práctico

Una persona se encuentra a 7 metros al este de un punto de referencia y otra a 7 metros al oeste.

Sus posiciones pueden representarse como +7 y -7.

Ambas tienen una distancia de 7 metros respecto del punto de referencia.

## Ideas clave
- El valor absoluto representa distancia al cero.
- Los números opuestos tienen el mismo valor absoluto.
- El valor absoluto de cero es cero.
- El resultado del valor absoluto nunca es negativo.

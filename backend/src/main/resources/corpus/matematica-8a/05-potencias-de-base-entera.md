- Fuente: Programa de Estudio MINEDUC (curriculumnacional.cl), redactado por el equipo para la demo

## Objetivo
Calcular potencias de base entera y reconocer el signo del resultado.

## Contenido

Una potencia indica cuántas veces se multiplica un número por sí mismo.

En (-2)³, la base es -2 y el exponente es 3.

(-2)³ = (-2) × (-2) × (-2) = -8.

## Signo del resultado

Si la base es negativa y el exponente es par, el resultado es positivo.

Ejemplo:
- (-3)² = (-3) × (-3) = 9.

Si la base es negativa y el exponente es impar, el resultado es negativo.

Ejemplo:
- (-2)³ = -8.

## Exponente cero

Toda potencia de base distinta de cero y exponente cero es igual a 1.

Ejemplo:
- 5⁰ = 1.

## Ideas clave
- El exponente dice cuántas veces se multiplica la base.
- Base negativa y exponente par: resultado positivo.
- Base negativa y exponente impar: resultado negativo.
- Cualquier número distinto de cero elevado a 0 es 1.

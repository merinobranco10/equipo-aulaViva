
# Operaciones con números enteros

- Curso: Matemática 8° básico A
- Colegio: Colegio Los Andes (demo)
- Unidad: Números
- Tema: Adición y sustracción de enteros

## Objetivo
Resolver operaciones de adición y sustracción utilizando números enteros.

## Adición con igual signo

Se suman los valores absolutos y se conserva el signo.

Ejemplos:
- (+3) + (+2) = +5.
- (-3) + (-2) = -5.

## Adición con distinto signo

Se restan los valores absolutos y se conserva el signo del número con mayor valor absoluto.

Ejemplo:
- (-8) + (+3) = -5.
- (+9) + (-4) = +5.

## Sustracción

Restar un número entero equivale a sumar su opuesto.

Ejemplos:
- 5 - 3 = 5 + (-3) = 2.
- 4 - (-2) = 4 + 2 = 6.
- -3 - 5 = -3 + (-5) = -8.

## Ejemplo práctico

Una cuenta tiene una deuda de $8.000 y recibe un abono de $3.000.

La operación es -8.000 + 3.000 = -5.000.

La deuda restante es de $5.000.

## Ideas clave
- Con signos iguales se suman los valores absolutos.
- Con signos diferentes se restan los valores absolutos.
- Restar es sumar el opuesto.
